# Logger

This are a collection of services for the logger.

## Usage

To run simply execute:

```bash
docker compose up
```

## Developers

Remove the commented lines in the `docker-compose.yaml` file:

```yaml
# command: "--dev" # To enable devloper mode
```

```yaml
# ports:
#   - "3306:3306"
```

Then execute:

```bash
docker compose up
```
